## 横向修正

- 主内容使用容器宽度，首页/视频/资料内容上限 680 点，普通表单上限 600 点；不使用设备屏幕宽度作为布局常量。图片按容器裁切，原始图片字节未改变。
- 新增 `TatiForm` 统一可滚动内容与底部主按钮，遵守系统安全区域和键盘压缩。房间、筛选、创建、礼物各自使用合适的面板高度，较长房间面板可展开。
- 视频列表播放采用填充裁切，与封面容器一致；详情仍保留等比播放。播放器归属、异步加载代次、离页/后台停止的原契约未改。
- 保留现有 `MediaViewport` 对实际 SDK 支持的 division/occlusion 保留区域处理；未通过尺寸变更重建播放器归属。Duo 仅作源码层面处理，没有双屏或折叠设备验收。
- 资料扩展字段、报告/草稿持久化、关注/拉黑、签到和礼物账本继续使用既有 VisitorStore。没有重新导入素材或重置用户数据。

## 静态证据与限制

- 对前一轮建立的 UI 基线复核：436 个原素材/运行时资源文件 SHA-256 无变化。
- 49 张图片与 16 段视频：来源及运行时副本均与已登记 SHA-256 一致；内容清单仍为 49 个头像/资料图、8 个房间封面映射、16 条视频。
- 直接字符串形式的 Art/Image 资源引用未发现缺失；五个 Tab 均保留选中态与 accessibilityLabel，没有 `Text(tab.rawValue)`。
- `git diff --check` 无空白错误。源码检查修正了新增容器、可选封面引用、圆角参数顺序及视图语句边界。
- 未执行编译、Swift 类型检查、测试、模拟器、设备、真实服务或支付验证。没有修改后的运行截图，因此字号视觉效果、具体设备断行、系统弹层最终高度和触摸效果仍不能声称已验收。
