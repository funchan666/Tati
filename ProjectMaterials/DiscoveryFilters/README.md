# Discovery filter control

Original artwork generated with the built-in image tool (Garden Host-Native workflow), 2026-10-22.

Direction: retain Tati's candy pink, yellow-lime and dark olive palette; give the filter action the same dimensional material as the chat and food-camera artwork. Keep the existing typography. Density and layout remain unchanged; motion is a brief press response only.

The original transparent PNG is `filter-sliders-original.png`. The app uses a 144 × 144 PNG at 3x in `discovery-filter-sliders.imageset`, fitted into a 44pt image inside a 48pt button. Both discovery tabs use this same component, while their saved filter selections stay independent. An active-count badge remains live native text. Reduce Motion disables scaling.

## Generation prompt

Use case: stylized-concept. Asset type: one original transparent raster UI icon for Tati, a playful food community iOS app. Create a polished chunky 3D FILTER / ADJUSTMENTS icon: exactly three short horizontal dark olive green rails stacked vertically, each with one glossy rounded slider knob, top knob toward right, middle toward left, bottom toward center-right. Knobs in bright candy pink and fresh yellow-lime with warm cream specular highlights. Big clean recognizable silhouette that reads at 40px. Friendly toy-like premium 3D rendering, same vocabulary as glossy pink chat bubbles and a pink food-camera icon. Slight front three-quarter view, mostly frontal so all three horizontal rails read clearly. Strong olive outlines/depth and smooth candy materials. Composition: centered single object, occupies about 85% of square canvas, isolated on true transparent alpha background, tiny contained contact shadows only. No square tile, no rounded-square container, no background, no text, no letters, no numbers, no watermark, no emoji, no tiny garnish, no extra symbols, no funnel, no detached decorative shapes. This is a functional filter control, lively but restrained.
