# Bundled reading fonts

Downloaded 2026-10-22 from the Google Fonts source repository:

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Fraunces: https://github.com/google/fonts/tree/main/ofl/fraunces

Both include the SIL Open Font License in the app Typography resources. Variable originals are retained here. Delivery files are static instances at the source optical-size default: DM Sans Regular / SemiBold and Fraunces SemiBold. No outlines or glyph repertoire were removed. App text uses Font.custom with relative text styles; unsupported scripts use the platform glyph fallback. Genuine OS sheets keep their native typography.

No runtime font URL, remote stylesheet or font-download entitlement is used. Verify Dynamic Type and Chinese/Japanese fallback on device before release.
