# Food film list refinement

2026-10-22. Native SwiftUI; local artwork generated with the built-in image tool through Garden's Host-Native workflow.

## Direction and implementation

Retain Tati's pink, lime and olive palette, original heading and local DM Sans typography. Put the moving-image entry first, with the author, dish caption and engagement on an ivory reading surface below it. The caption is larger and can occupy three lines. The dark follow button changes to a lime “Following” state. Likes, comments and content options each have at least 44pt hit areas. The save-video entry pairs the existing original food-camera artwork with an explicit action label.

The play control is an original porcelain-plate interpretation, not a system symbol. `porcelain-play-original.png` retains the generated source; the application uses the 192px transparent delivery file in `film-porcelain-play.imageset`. The artwork is displayed at 58pt. Existing original heart, chat and options art is reused.

No new player is created in the list. The existing navigation, follow store, like counts, comments, report/block sheets and post ownership checks remain in place. Search and My Videos also use the shared card. Author controls and engagement reflow for narrow containers and accessibility text sizes. Press feedback lasts 120ms; Reduce Motion disables scaling. No perpetual list animation was added.

## Saved generation prompt

One round cream porcelain button like a smooth tiny dinner plate, chunky softly beveled rim in fresh yellow-lime with a thin dark olive underside, and a single bold glossy candy-pink right-facing triangular play mark inset prominently in the center. The pink triangle is large and reads instantly at 48 pixels. Front facing orthographic, minimal depth, symmetrical clean silhouette, beautifully restrained 3D studio light and small contained underside shadow. Palette only warm cream, bright candy pink, yellow-lime and dark olive. No food decorations, no utensils, no characters, no extra symbols, no sparkles, no text, no lettering, no background rectangle, no interface mockup, no watermark. The standalone round button fills 86% of a square canvas, ample clean transparent margins. Match a playful polished 3D food-camera and candy-slider icon system. Render as a production-ready isolated button asset.
